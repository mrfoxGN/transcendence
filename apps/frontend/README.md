# DevUP frontend

React + TypeScript + Vite. Changes in this directory implement the DevUP interface against the repository's existing APIs.

- [Frontend structure and development](docs/FRONTEND_GUIDE.md)
- [Design foundations and reusable components](docs/DESIGN_SYSTEM.md)
- [Migration notes](UI_MIGRATION.md)
- [Current API limitations](API_LIMITATIONS.md)

There is no component showcase route. The reusable system is used directly by production pages.

Run `npm run check` and `npm run build` before committing. See the frontend guide for fixture-based browser verification.
